# SellerSprite 关键词调研 v1.0.0 启动说明

绿色便携版：无需安装 Python / Node / MCP 客户端，解压即可用。

## 使用

1. 解压本目录到本地可写位置（不要放在系统保护目录）。
2. 双击 `SellerSprite关键词调研.exe`。
3. 首次使用先到「设置」页：
   - 填写 SellerSprite **Secret Key**（接入地址默认 `https://mcp.sellersprite.com/mcp`）；
   - 填写模型 **Base URL / API Key / 模型名**（OpenAI 兼容，如 DeepSeek：
     `https://api.deepseek.com` + `deepseek-v4-flash`；
     注意：旧模型名 `deepseek-chat` 已停用，当前 API 仅支持 V4 系列）;
   - 点「测试连接」「测试模型」确认后保存。
   - 密钥只写入 Windows 凭据管理器，settings.json 不含密钥。
4. 到「新建任务」页：选择站点、粘贴同站点 ASIN（去重后 ≤20 个）、快照月份（yyyyMM，留空=当月）、
   可选填「任务名称」（仅列表显示，可双击列表任务名重命名；不影响目录名与 Excel 文件名）。
   - 多站点调研：点「＋添加站点组」，每个站点组一个站点、≤20 个 ASIN。
5. 点「核算预算」查看调用量明细（>30 次会要求确认），确认后「创建任务并开始执行」。
6. 任务列表页可看实时日志、限流倒计时；完成后打开任务目录取 Excel 报告。
7. 批量执行：列表多选（Ctrl/Shift 或「全选」）→「一键排队执行」按顺序串行跑，
   失败自动跳过继续；「停止队列」取消当前并跳过剩余；完成弹汇总（成功/失败/跳过）。

## 重要边界

- SellerSprite 调用固定 ≤8 次/滚动 60 秒（滑动窗口 + 相邻 ≥7.5 秒）；限流等待属正常状态，不会中断任务。
- 单站点组 ASIN 上限 20（去重后）；超限会阻止创建，不静默截断。
- 20 个 ASIN、无 Node、默认 10 个趋势词的标准任务：基准 33 次调用（约 4-5 分钟，取决于限流等待）。
- 模型分析自动拆 4 段执行（容量与稳定性设计），失败段自动重试、最终保守降级并在报告中标注。
- 断点续跑：任务中断后点「开始/继续执行」只补缺失环节，已完成的 MCP 调用不重复。
- 任务目录默认在 `文档\SellerSprite关键词调研`；删除任务可选「仅移出列表」或「移入回收站」。

## 自检

命令行运行 `SellerSprite关键词调研.exe --selfcheck` 可验证引擎资产完整性（返回 JSON，exit 0=正常）。
